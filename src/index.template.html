按键说明

底部按钮可用鼠标或手指点：单击触动，双击锁住（再双击解锁），与原版鼠标模式相同。键盘：

全停小键盘 .，或 V
得分小键盘 0，或 T
開始小键盘 Enter / Enter / 空格
押小键盘 +，或 B
上分F2，或顶栏「上分」
洗分 / 设置开关 / 账目开关F3 / F4 / F5（设置开关打开时可看原版「開關設定說明」画面）
全屏F11

玩法：先上分（F2），按「押」加押分到最低押分以上，按「開始」转动；中奖后等 TAKE SCORE / DOUBLE UP 闪动时按「比倍」猜大小或按「得分」收分。

声音需要先点一下画面或按任意游戏键（浏览器限制）。
